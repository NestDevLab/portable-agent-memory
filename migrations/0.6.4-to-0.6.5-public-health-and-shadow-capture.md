# PAM 0.6.4 to 0.6.5 — public health and shadow capture

PAM 0.6.5 adds portable health reporting, an official Agentwheel skill, and a
validate-only capture proposal format. It does not require a backend or change
the `pam-graph-v1` record shape.

## Upgrade

1. Update the public PAM toolkit to version `0.6.5` through its normal Git or
   package lifecycle.
2. Install or update the `portable-agent-memory` skill through the owning
   Agentwheel package; do not copy it into a runtime directory manually.
3. Run `npm run pam:health -- --workspace-root <workspace-root>` with the
   graph, version, scenario, and source-registry paths for that workspace.
4. Treat `BLOCKED` as invalid structure and `ATTENTION` as an explicit review
   queue for freshness, retrieval, coverage, or efficiency.
5. Validate durable-knowledge proposals with `npm run pam:capture -- plan`.
   Capture remains shadow-only: it never writes canonical sources or graph
   records.

## Validation

- `npm run migrations:check` passes.
- `npm test` passes.
- The health report includes only aggregate metrics and relative paths.
- Capture proposals include a source path, SHA-256 digest, confidence,
  sensitivity, and evidence date.
