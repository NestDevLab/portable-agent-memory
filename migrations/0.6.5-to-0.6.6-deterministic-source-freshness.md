# PAM 0.6.5 to 0.6.6 — deterministic source freshness

PAM 0.6.6 makes source freshness independent from filesystem copy and checkout
timestamps when a source registry provides a SHA-256 content digest. It also
allows explicit age and source-change exemptions for append-only or immutable
sources. Existing registries keep the 0.6.5 timestamp and 30-day behavior.

## Upgrade

1. Update the toolkit to version `0.6.6` through the normal Git or package
   lifecycle.
2. Add an optional `sha256` field to registered sources that require
   deterministic content-change detection.
3. Add optional `freshness.maxAgeDays` and
   `freshness.trackSourceChanges` fields only where the source semantics need
   to override the defaults.
4. Run PAM health twice and confirm that an unchanged second run reports no
   source drift.

## Validation

- `npm run migrations:check` passes.
- `npm test` passes.
- Touching an unchanged digest-pinned source does not create drift.
- Changing its contents does create drift.
- Explicit append-only sources can be exempted without changing graph nodes.
